### Description
Python ko time kaise pata? ⏰ datetime = Python ki ghadi!
now() se abhi ka time, strftime() se sundar format, hour se dukaan khuli ya band ka faisla. ☕🐍

📌 Code:
from datetime import datetime

now = datetime.now()
print(now.strftime("%d-%m-%Y %H:%M"))   → 18-10-2026 09:30

if 8 <= now.hour < 22:
    print("Dukaan khuli hai!")
else:
    print("Kal aana!")

(aapka time alag hoga 😄) · %H ghanta · %M minute · %d din
