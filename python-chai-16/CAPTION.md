### Description
Har baar cheeni batao, warna TypeError! 😩 Fix: default value.
def chai_banao(cheeni=1): kuch na bolo toh 1 chammach, bolo toh tumhari marzi! ☕🐍

📌 Code:
def chai_banao(cheeni=1):
    print(f"Cheeni: {cheeni} chammach")

chai_banao()     → Cheeni: 1 chammach
chai_banao(0)    → Cheeni: 0 chammach
chai_banao(3)    → Cheeni: 3 chammach

⚠️ Rule: default wale parameters peeche: def chai_banao(size, cheeni=1)
