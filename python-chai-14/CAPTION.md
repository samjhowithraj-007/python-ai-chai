### Description
"Total: Rs " + total → TypeError! 😱 Python text aur number ko + se nahi jodta.
Fix: f-string! Quotes se pehle f lagao, { } mein value bharo. str() ki zaroorat hi nahi. ☕🐍

📌 Code:
total = 50
cups = 3
print(f"{cups} cup chai: Rs {total}")
print(f"Tip ke saath: Rs {total + 10}")

Output:
3 cup chai: Rs 50
Tip ke saath: Rs 60
