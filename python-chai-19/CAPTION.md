### Description
Har dukaan ke liye alag variable? dukaan1_naam, dukaan2_cups… thak jaoge! 😩
class = dukaan ka naksha. Ek baar banao, phir jitni chaho utni dukaan (object)! ☕🐍

📌 Code:
class ChaiDukaan:
    def __init__(self, naam):
        self.naam = naam
        self.cups = 0

    def bechna(self):
        self.cups += 1
        print(self.naam, self.cups)

raju = ChaiDukaan("Raju")
pappu = ChaiDukaan("Pappu")
raju.bechna(); raju.bechna(); pappu.bechna()
→ Raju 1 · Raju 2 · Pappu 1

__init__ = nayi dukaan setup · self = yeh wali dukaan · class ke andar def = method
