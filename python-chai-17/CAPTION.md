### Description
Ravi do baar aaya, toh list ne 4 gin liye! 🤔 Asli customer kitne?
set = koi double nahi. set(log) se double hatao, len() se asli ginti! ☕🐍

📌 Code:
log = ["Ravi", "Neha", "Ravi", "Amit"]
unique = set(log)
print(len(log), len(unique))      → 4 3

unique.add("Sita")
print("Ravi" in unique, "Zoya" in unique)   → True False

add() = naya ho toh hi judega · in = hai ya nahi · set ka order fix nahi
