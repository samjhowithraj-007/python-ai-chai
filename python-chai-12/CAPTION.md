Kal ka bill kahan? 🤔 Python file padho! | Python Chai Part 12 #shorts

### Description
Kal raat bill.txt mein save kiya tha… aaj wapas kaise laayein? 🤔
"r" se file padho, read() se poora text milega. Aur naya order? "a" (append) se neeche jodo, purana bill safe! ☕🐍

📌 Code:
with open("bill.txt", "r") as f:
    bill = f.read()
print(bill)

with open("bill.txt", "a") as f:
    f.write("\nAdrak: Rs 15")

"r" = padho · "w" = mita ke naya likho · "a" = neeche jodo
